    base_url="http://127.0.0.1:8000/v1",
    api_key="sk-agy-YOUR_KEY",
)

stream = client.chat.completions.create(
    model="gpt-4o",  # routed to official AGY model
    messages=[{"role": "user", "content": "Refactor this module"}],
    stream=True,
    user="agent-thread-01"
)
for chunk in stream:
    print(chunk.choices[0].delta.content or "", end="", flush=True)
ARCHITECTURE

100% Terms-of-Service compliant by design.

AGYRouter never scrapes cookies or spoofs headers. Every completion executes directly through the official agy CLI binary installed on your machine.

100% ToS-Compliant Bridge

Invokes the official agy -p ... --output-format stream-json subprocess on your machine. No private API reverse-engineering or token theft.

Delta-Turn Token Savings

Persists thread mappings in SQLite and sends only the latest user turn when continuing via --conversation, preventing duplicate history tokens.

Cloudflare Free Tunnel

Auto-downloads the official cloudflared binary in one click and enforces --protocol http2 for reliable Quick Tunnels and Named Tunnels.

30-Day Persistent Auth

HMAC-SHA256 HttpOnly session cookies plus token fallback keep you signed in across browser restarts without repeated login prompts.

Cross-OS 24/7 Services

agy-router service install detects your OS automatically and configures Windows Task Scheduler, Linux systemd --user, or macOS launchd.

SQLite WAL Observability

Inspect per-key requests, latency, and model routing live in the dashboard with zero external database dependencies.

GET STARTED

Up and routing in 30 seconds.

Requires Python 3.10+ and an authenticated Google Antigravity CLI (agy models works in your terminal).

git clone https://github.com/kikik27/AGYRouter.git
cd AGYRouter
.\agy-router.bat setup
.\agy-router.bat start --tunnel
